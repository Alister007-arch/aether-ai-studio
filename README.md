# Aether AI Studio ⚡

A modern GenAI & RAG studio powered by Google Gemini, LangChain, and ChromaDB.

## Features
- 💬 **Interactive Gemini Chat** with configurable models & system instructions
- 📚 **RAG & PDF Knowledge Base** with MMR semantic search
- 🔬 **Embeddings & Similarity Inspector**
- 🎨 **Modern Glassmorphic UI** with multiple superhero & luxury themes

## Deployment on Hugging Face Spaces
1. **Repository Secret**:
   In your Space **Settings** -> **Variables and secrets**, add:
   - `GOOGLE_API_KEY`: Your Gemini API key from Google AI Studio.
